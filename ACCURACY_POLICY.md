# OpportunityRadar — Non-Negotiable Accuracy Rules

1. Official source is the authority.
2. Every published record must have a source URL and verification date.
3. If the source does not publish a field, show "not published" rather than infer it.
4. AI may summarize, classify and match, but cannot invent source facts.
5. Eligibility is always presented as guidance, never as a guarantee.
6. Deadlines are stored with timezone when the source provides one.
7. Participant counts are labeled as observed unless the organizer explicitly states they are final.
8. Stale records are removed or flagged after their verification window expires.
9. Change detection should compare important fields and record old/new values.
10. Users are always directed to the official source before applying.

## Trust levels

A = official rules/details checked within 7 days
B = official landing/schedule page checked within 7 days
C = directory/index record not independently verified

Only A/B records should be used for recommended results. C records may appear as needs-verification items and should not be ranked as fully verified opportunities.
