# OpportunityRadar

Find opportunities you can actually apply for.

OpportunityRadar is a source-first opportunity finder for grants, competitions, hackathons, fellowships and related programs. The project prioritizes official-source accuracy, verification dates, transparent matching, and automated refreshes.

## Principles
- Official source wins over AI guesses.
- Unknown fields stay unknown.
- Eligibility is guidance, never a guarantee.
- Every published record keeps provenance and a verification date.

## Status
Early MVP: ingestion and matching foundations are under active development.
