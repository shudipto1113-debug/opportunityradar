# Google setup remaining

## Search Console
1. Add `https://opportunityradar.shudipto1113.workers.dev/` as a URL-prefix property in Google Search Console.
2. Verify ownership using the HTML tag or DNS method Google provides.
3. Submit `/sitemap.xml`.

Search Console's API can later be authorized to pull search analytics into the owner dashboard. The API supports dimensions including country, device, page and query and requires authorization.

## AdSense
The site is technically prepared with public privacy, terms, contact and editorial standards pages. AdSense still requires the site owner to apply, verify site ownership and complete Google's account/site review. Do not add a fake publisher ID or fake `ads.txt` entry. The actual AdSense publisher ID must come from the owner's approved Google account.

## Important
These are account-ownership steps and cannot be completed safely by committing credentials to the public repository.
